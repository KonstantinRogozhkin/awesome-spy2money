# Как помочь проекту

Спасибо, что помогаете сделать документацию Spy2Money лучше.

## Что принимается

- Исправления неточностей и опечаток в документации.
- Новые полезные ссылки: учебные материалы по опционам, darkpool, волатильности, крипто-опционам и AI-агентам.
- Примеры использования платформы и MCP-сервера.

## Правила для ссылок

- Одна ссылка — одна строка в формате `- [Название](https://ссылка) — короткое описание.`
- Описание начинается с заглавной буквы и заканчивается точкой.
- Только HTTPS-ссылки, работающие без регистрации, если это не официальный ресурс Spy2Money.
- Без реферальных ссылок, рекламы, «сигналов» и обещаний доходности.
- Добавляйте ссылку в подходящий раздел; если раздела нет — предложите его в описании Pull Request.

## Справочник виджетов

Страницы в `docs/widgets/` синхронизированы со встроенной справкой приложения. Если заметили расхождение с тем, что показывает платформа, откройте [Issue](https://github.com/KonstantinRogozhkin/awesome-spy2money/issues) с названием виджета и описанием.

## Как отправить изменения

1. Сделайте fork репозитория.
2. Внесите изменения в отдельной ветке.
3. Откройте Pull Request с кратким описанием, что и зачем изменено.

Отправляя изменения, вы соглашаетесь передать их в общественное достояние по [CC0 1.0](./LICENSE).

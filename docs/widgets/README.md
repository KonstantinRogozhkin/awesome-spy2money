## Опционный поток рынка

| Виджет | Назначение |
| --- | --- |
| [Рыночный поток опционов](./market-flow.md) | Сопоставляет поток опционов рынка или выбранного тикера с ценой. Помогает увидеть, когда меняется характер активности и насколько широко она распределена. |
| [Market Netflow V2: премия опционного потока](./market-netflow-v2.md) | Показывает рыночный поток CALL/PUT рядом с ценой SPY и позволяет сравнить новый рыночный индикатор потока (режим NEW) с исходным расчётом Market Netflow. |
| [Market Net Flow Expiry](./market-netflow-expiry.md) | Разделяет опционный поток по сроку экспирации и типу инструментов, чтобы краткосрочная активность не маскировала остальной рынок. |
| [Топ тикеров по Net Premium](./market-top-net-impact.md) | Помогает найти инструменты с заметным вкладом в чистую премию и перейти от общего рынка к конкретным тикерам. |
| [Карты опционных ордеров](./options-map.md) | Ранжируют тикеры по выбранной группе потока и показывают состав премии по сторонам исполнения. |
| [Сканер опционного потока](./options-order-flow.md) | Разбирает поток на отдельные исполнения/агрегаты и помогает проверить, какие контракты стоят за движением графиков. |
| [Market Flow Alerts](./market-flow-alerts.md) | Лента алертов необычной опционной активности по рынку: крупные sweep и floor сделки, объём выше открытого интереса, премия выше порога. |
| [Секторные ETF](./sector-flow.md) | Сравнивает опционный поток 11 секторных SPDR ETF (XLB, XLC, XLE, XLF, XLI, XLK, XLP, XLRE, XLU, XLV, XLY): где за день больше бычьей или медвежьей премии. |
| [Лидеры по объёму](./volume-leaders.md) | Компактные графики помогают быстро сравнить выбранные активные тикеры и перейти к подробному анализу. |
| [Скринер настроений](./sentiment-screener.md) | Сравнивает тикеры по агрегированным показателям опционной активности и помогает отобрать кандидатов для подробного анализа. |

<a id="ticker"></a>

## Анализ тикера

| Виджет | Назначение |
| --- | --- |
| [Ticker Net Prem Realtime](./ticker-net-prem.md) | Сопоставляет накопленные Call/Put премии и объём с ценой выбранного тикера за выбранный период. |
| [Ticker Overview Strikes](./ticker-overview-strikes.md) | Показывает, на каких страйках развивается net-премия, и помогает отличить общий поток от концентрации в отдельных уровнях. |
| [Ticker Greek Flow](./ticker-greek-flow.md) | Показывает поток чувствительностей Delta/Vega вместе с ценой, чтобы различать активность, связанную с направлением цены и с волатильностью. |
| [Ticker Greek Spot Realtime](./ticker-greek-spot.md) | Показывает модельную чувствительность опционной структуры к цене, времени и волатильности, включая распределение по страйкам и срокам. |
| [Ticker GEX Levels](./ticker-gex-levels.md) | Наносит ключевые уровни модельной гамма-экспозиции дилеров на цену торгового дня: где опционные позиции могут сдерживать или ускорять движение. |
| [Ticker Gamma Profile](./ticker-gamma-profile.md) | Совмещает минутные свечи с профилем модельной гамма-экспозиции по страйкам, чтобы видеть, где относительно цены сосредоточена Gamma и как она меняется в течение сессии. |
| [Ticker IV Term Structure](./ticker-iv-term-structure.md) | Показывает подразумеваемую волатильность ATM-опционов тикера по каждой реальной экспирации и её изменение с прошлой сессии: насколько дороги ближние опционы относительно дальних. |
| [Ticker Trade Ideas](./ticker-trade-ideas.md) | Объединяет волатильность, характеристики исполнения и опционные уровни для предварительного отбора идей. |
| [Ticker Option Contract](./ticker-option-contract.md) | Позволяет перейти от активных цепочек к конкретному контракту и изучить его торговлю внутри дня. |
| [Ценовой график TradingView](./ticker-tradingview.md) | Даёт ценовой контекст для опционного потока: тренд, диапазон, реакцию на уровни и события. |
| [График уровней](./level-chart.md) | Сопоставляет цену тикера с рассчитанными источником уровнями для наблюдения за удержанием, пробоем и возвратом. |

## Darkpool (внебиржевые сделки)

| Виджет | Назначение |
| --- | --- |
| [Darkpool — карты денежного потока](./darkpool-map.md) | Сравнивает внебиржевой денежный оборот акций и ETF за выбранный период и объясняет различие режима отбора и рейтинга. |
| [Darkpool TOP BUY](./market-darkpool-top-net-map-call.md) | Находит тикеры с покупательской долей не меньше 70% денежного оборота выбранных сторон и ранжирует их по обороту. |
| [Darkpool TOP SELL](./market-darkpool-top-net-map-put.md) | Находит тикеры с продавцовской долей не меньше 70% денежного оборота выбранных сторон и ранжирует их по обороту. |
| [Darkpool TOP STOCKS](./market-darkpool-top-net-map-stocks.md) | Сравнивает денежный оборот внебиржевых сделок акций и ADR по классификации инструмента источника. |
| [Darkpool TOP ETF](./market-darkpool-top-net-map-etf.md) | Сравнивает денежный оборот внебиржевых сделок ETF, кроме инструментов отдельного списка Short ETF источника. |
| [Darkpool TOP SHORT ETF](./market-darkpool-top-net-map-etf-short.md) | Показывает оборот инструментов из отдельного списка Short ETF источника, куда входят inverse/short и отдельные волатильностные фонды. |
| [Сканер darkpool потока — отдельные принты](./market-darkpool-flow.md) | Показывает отдельные внебиржевые исполнения акций и ETF и позволяет проверить сделки, из которых формируются карты и график по тикеру. |
| [Ticker Darkpool Net Prem — график по тикеру](./ticker-darkpool-net-prem.md) | Показывает внебиржевые исполнения выбранной акции или ETF по временным интервалам: цену, денежный оборот сторон и накопительную разность объёмов акций. |

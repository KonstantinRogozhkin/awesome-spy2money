# Сканер опционного потока

> Разбирает поток на отдельные исполнения/агрегаты и помогает проверить, какие контракты стоят за движением графиков.

**Раздел:** [Опционный поток рынка](./README.md#options-flow) · **Идентификатор виджета:** `optionsOrderFlow`

## Коротко

| Параметр | Значение |
| --- | --- |
| Данные | Отдельные опционные сделки и агрегаты |
| Премия | Цена × контракты × 100 |
| Обновление | Уведомления об изменении источника и опрос 30 с |

## Что показывает

- **Ticker, CALL/PUT, Strike, Spot** — Тикер, тип опциона, цена исполнения и цена базового актива. CALL — право купить, PUT — право продать; тип опциона без стороны сделки не определяет направленность.
- **Expiry / DTE / время** — Дата истечения, остаток дней и время сделки. Период сделок и срок контрактов — независимые фильтры.
- **Volume / OI** — Volume — торгуемые контракты; OI — открытый интерес из доступного снимка. Volume > OI не доказывает открытие новых позиций: контракт может перепродаваться.
- **Premium** — Денежный размер сделки. Обычно цена контракта × количество × мультипликатор; проверяйте спецификацию нестандартных контрактов.
- **Side / Sentiment** — ASK/ABOVE совместимы с покупкой, BID/BELOW — с продажей; MID менее определён. Sentiment — производная классификация, а не прогноз.
- **Type / Moneyness** — SWEEP/BLOCK и другие типы описывают характер исполнения; ITM/ATM/OTM — положение страйка. SWEEP не доказывает инсайдерскую информацию.

## Как считается

- **Сторона сделки.** ASK-сторона — цена исполнения выше середины котировки ((BID + ASK) / 2 < цена), BID-сторона — ниже середины. Ровно по середине — MID, без определяемой стороны — No side (поздние, внеочередные и cross-сделки).
- **Sweep / Floor / Cross.** Sweep — заявка, исполненная на нескольких биржах подряд; Floor — сделка с кодом торгового зала; Cross — встречная сделка внутри одного посредника.
- **Bullish / Bearish premium.** Бычья премия = CALL на ASK + PUT на BID, медвежья = CALL на BID + PUT на ASK; MID и сделки без стороны исключены.
- **Повторные исполнения.** Несколько сделок по одному контракту за миллисекунды: одна крупная заявка сводится с несколькими встречными или одновременно действуют несколько участников. Признак срочности, не направления.
- **Vol > OI.** Объём дня больше открытого интереса: признак активности, но не доказательство открытия новых позиций.

## Управление

Фильтруйте тикер, CALL/PUT, тип, сторону, moneyness, премию и DTE. Знак ≥/≤ меняет смысл порога. Сортировка и пагинация показывают часть выборки; пустой результат при фильтрах не означает отсутствие рынка.

## Как читать

1. Установите дату и тикер, затем ограничьте размер сделки и срок.
2. Сопоставьте премию с ликвидностью, OI и сторонами соседних исполнений.
3. Откройте детали строки/контракта, проверьте цену акции и возможную многоногую конструкцию.

## Пример

Крупный CALL на BID может быть продажей или закрытием купленного колла. Считать любой крупный CALL ставкой на рост ошибочно.

## Ограничения

ASK/BID — классификация исполнения относительно котировок, а не установленная личность покупателя. Сделка может закрывать позицию, быть хеджем или частью спреда. MID/неопределённая сторона не доказывает направление. Чистая премия не равна притоку денег в акцию.

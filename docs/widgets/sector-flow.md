# Секторные ETF

> Сравнивает опционный поток 11 секторных SPDR ETF (XLB, XLC, XLE, XLF, XLI, XLK, XLP, XLRE, XLU, XLV, XLY): где за день больше бычьей или медвежьей премии.

**Раздел:** [Опционный поток рынка](./README.md#options-flow) · **Идентификатор виджета:** `sectorFlow`

## Коротко

| Параметр | Значение |
| --- | --- |
| Данные | Классифицированная опционная премия 11 секторных SPDR ETF |
| Единицы | Доллары (K, M, B) |
| Обновление | Снимок, опрос раз в 5 минут; без realtime |
| Период | Дата снимка; без календаря и истории |

## Что показывает

- **Бычья премия** — CALL на ASK плюс PUT на BID. Это не вся премия CALL: CALL на BID — медвежий.
- **Медвежья премия** — CALL на BID плюс PUT на ASK.
- **Баланс** — Бычья минус медвежья, в долларах; показатель по умолчанию. Зелёный бар — не ниже нуля, красный — ниже.
- **Сводные суммы** — Плашки над графиком — суммы по ETF с обеими премиями. ETF без пары исключается из графика и сумм; тогда видно «Данные по N из 11 ETF».

## Как считается

- **Бычья / медвежья.** Бычья = CALL на ASK + PUT на BID; медвежья = CALL на BID + PUT на ASK. MID и сделки без стороны не входят.
- **Баланс и суммы.** Баланс = бычья − медвежья, только при обеих премиях; пропуск не равен нулю. Суммы — по тем же ETF.
- **Сторона сделки.** ASK-сторона — цена исполнения выше середины котировки ((BID + ASK) / 2 < цена), BID-сторона — ниже середины. Ровно по середине — MID, без определяемой стороны — No side (поздние, внеочередные и cross-сделки).

## Управление

Плашки «Бычья», «Медвежья», «Баланс» переключают метрику; бары сортируются по ней. Кнопка обновления — ручной запрос. Тикера, календаря и истории нет: в шапке дата снимка.

## Как читать

1. На «Балансе» сверху сектора с перевесом бычьей премии, снизу — медвежьей.
2. Сверьте бычью и медвежью премию: большой баланс может дать малый поток с одной стороны.
3. В подсказке — валовые премии CALL/PUT, контракты и изменение цены ETF к закрытию.

## Пример

XLK: бычья $90 млн, медвежья $50 млн, баланс +$40 млн — перевес бычьих сделок в опционах ETF, а не рост всех акций сектора.

## Ограничения

Только опционы самих ETF. Сторона — по котировке в момент сделки, не намерение: хеджи и спреды тоже в суммах. Снимок раз в 5 минут, без realtime и LIVE; дата снимка не подтверждает время сделок. Нужен полный доступ.

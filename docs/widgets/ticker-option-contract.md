# Ticker Option Contract

> Позволяет перейти от активных цепочек к конкретному контракту и изучить его торговлю внутри дня.

**Раздел:** [Анализ тикера](./README.md#ticker) · **Идентификатор виджета:** `tickerOptionContract`

## Коротко

| Параметр | Значение |
| --- | --- |
| Данные | Самые активные контракты и минутная торговля выбранного |
| Порог | Контракты с объёмом меньше 200 источник не возвращает |
| Обновление | Скринер — 30 с, минутные данные — 60 с |

## Что показывает

- **Chain / Last / Low–High** — Идентификатор контракта содержит тикер, экспирацию, CALL/PUT и страйк. Last — последняя сделка, Low–High — диапазон наблюдавшихся цен; Last не гарантирует доступную цену входа.
- **Volume / OI / OI ± / OI ± %** — Объём торгов, открытый интерес и его изменение относительно базового снимка. OI обновляется иначе, чем сделки; изменение OI нельзя привязать к одному принту.
- **Bid/Ask Vol** — Объём, классифицированный по сторонам котировки. Середина спреда и неизвестная сторона могут не давать направления.
- **Bid / Mid / Ask / No Side / Avg Fill** — Внутридневные серии по стороне исполнения и средней цене заполнения. Объём и цена используют разные оси.
- **Сканер: OT / Premium / контракт** — Тип опциона, денежный размер и конкретная цепочка помогают связать агрегат с отдельными сделками.

## Как считается

- **Сторона сделки.** ASK-сторона — цена исполнения выше середины котировки ((BID + ASK) / 2 < цена), BID-сторона — ниже середины. Ровно по середине — MID, без определяемой стороны — No side (поздние, внеочередные и cross-сделки).
- **Объём по сторонам.** Объём контракта делится на ASK, BID, MID и No side. Multileg — часть спреда, ролла или кондора; Stock multi-leg — связка с акциями (например, покрытый колл).
- **Sweep / Floor / Cross.** Sweep — заявка, исполненная на нескольких биржах подряд; Floor — сделка с кодом торгового зала; Cross — встречная сделка внутри одного посредника.
- **Avg Fill.** Средневзвешенная по объёму цена исполнения за интервал.
- **Символ контракта.** Тикер + дата экспирации ГГММДД + C/P + страйк × 1000 восемью цифрами: AAPL261218C00200000 — CALL AAPL $200, экспирация 18.12.2026.

## Управление

TOP VOLUME выбирает активно торгуемые цепочки, TOP OI — большой открытый интерес. После выбора контракта проверьте его полное имя, срок и страйк. В деталях переключайте «Объём по сторонам» и «Минутные данные»; разделитель меняет высоту панелей. Tooltip и таблица помогают прочитать один временной срез.

## Как читать

1. Выберите цепочку по нужному критерию и проверьте ликвидность.
2. Сопоставьте цену заполнения с BID/ASK и объёмом.
3. Проверьте базовый актив, срок и возможные связанные ноги.

## Пример

Рост Volume при неизменном OI в течение дня не означает отсутствие новых позиций: OI может быть ещё не обновлён.

## Ограничения

ASK/BID — классификация исполнения относительно котировок, а не установленная личность покупателя. Сделка может закрывать позицию, быть хеджем или частью спреда. MID/неопределённая сторона не доказывает направление. Чистая премия не равна притоку денег в акцию. Малоликвидные Last и Low–High могут быть устаревшими; комиссии и спред ухудшают исполнимый результат.

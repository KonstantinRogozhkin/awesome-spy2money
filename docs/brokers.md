# Брокеры и портфель

Раздел [Интеграции](https://app.spy2money.com/app/integrations) показывает портфель подключённых брокерских счетов рядом с аналитикой платформы.

## Поддерживаемые брокеры

| Брокер | Что доступно |
| --- | --- |
| **Freedom24 / Tradernet** | Счета, позиции и остатки; ключи Tradernet API V3 |
| **Bybit** | Портфель, остатки и позиции; Testnet и Mainnet используют разные ключи |

Поддерживается один счёт Bybit и один счёт Freedom на пользователя.

## Подключение

1. Откройте [Интеграции](https://app.spy2money.com/app/integrations) и нажмите «Добавить».
2. Выберите брокера и вставьте API-ключи. Для анализа портфеля достаточно ключей **только на чтение**.
3. После проверки ключей появится переключатель счёта в шапке страницы.

Сохранённые ключи и подтверждённый доступ к данным отображаются отдельно: если брокер отклонил ключ, страница покажет это явно.

## Страница портфеля

- Остатки, позиции и ключевые показатели в общей редактируемой сетке; «Сетка» в верхней панели меняет порядок и размеры.
- Поиск активов над прокручиваемым списком, точные значения — в раскрытии строки.
- Личный порядок и размеры карточек сохраняются в аккаунте; балансы и ключи в настройки раскладки не попадают.

## Безопасность

- Ключи передаются только на сервер Spy2Money и хранятся в зашифрованном виде; браузер их не сохраняет.
- **Торговля по умолчанию выключена.** Отправка заявок требует отдельной серверной политики и допуска; без них любые торговые действия отклоняются.
- Перед любой заявкой формируется предварительный просмотр, который действует 5 минут; одна заявка не может быть отправлена дважды.
- Рекомендуем создавать отдельный API-ключ только для Spy2Money, с минимальными правами и ограничением по IP, если брокер это поддерживает.

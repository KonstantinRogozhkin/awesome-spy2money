# Глоссарий

Термины, которые встречаются в виджетах Spy2Money.

| Термин | Значение |
| --- | --- |
| **Options flow** | Поток опционных сделок: кто, по каким контрактам и на какую сумму торгует. |
| **Premium (премия)** | Денежная сумма сделки: цена контракта × 100 × количество контрактов. |
| **Net Premium** | Премия на ASK минус премия на BID, отдельно по CALL и PUT. |
| **ASK / BID / MID** | Классификация исполнения относительно котировки: выше середины, ниже середины, ровно по середине. |
| **Sweep** | Крупный ордер, исполненный по частям сразу на нескольких биржах; часто признак срочности. |
| **Floor trade** | Сделка, проведённая через операционный зал биржи. |
| **Multi-leg** | Сделка из нескольких ног (спред, стрэддл и т. п.); направление одной ноги не отражает позицию целиком. |
| **DTE** | Days to expiration — число дней до экспирации контракта. |
| **0DTE** | Контракты с экспирацией в текущий день. |
| **Open Interest (OI)** | Число открытых контрактов на конец предыдущей сессии. |
| **Volume > OI** | Объём за день выше открытого интереса — признак появления новых позиций. |
| **Strike (страйк)** | Цена исполнения опциона. |
| **ATM / ITM / OTM** | Страйк около текущей цены / «в деньгах» / «вне денег». |
| **Delta** | Изменение цены опциона при изменении цены актива на $1. |
| **Gamma** | Скорость изменения Delta; определяет, насколько активно маркетмейкер перехеджирует позицию. |
| **Vega** | Чувствительность цены опциона к изменению волатильности. |
| **Theta** | Потеря стоимости опциона со временем. |
| **Vanna** | Изменение Delta при изменении волатильности. |
| **Charm** | Изменение Delta с течением времени. |
| **GEX** | Gamma exposure — модельная гамма-экспозиция дилеров по страйкам. |
| **Gamma flip** | Уровень, где модельная суммарная Gamma меняет знак. |
| **Call / Put wall** | Страйк с наибольшей концентрацией модельной Gamma по коллам / путам. |
| **Max Pain** | Страйк, при котором суммарная стоимость опционов к экспирации минимальна. |
| **IV** | Implied volatility — подразумеваемая волатильность, заложенная в цену опциона. |
| **Term structure** | IV по срокам экспирации: насколько дороги ближние опционы относительно дальних. |
| **Realized volatility** | Фактическая волатильность цены за прошедший период. |
| **Darkpool** | Внебиржевые площадки (ATS), где сделки с акциями исполняются вне публичного стакана. |
| **Print** | Отдельная отчётная запись о сделке. |
| **Sector ETF** | Секторные фонды SPDR: XLB, XLC, XLE, XLF, XLI, XLK, XLP, XLRE, XLU, XLV, XLY. |
| **RTH** | Regular trading hours — основная сессия рынка США, 09:30–16:00 по Нью-Йорку. |

# Доступ, оплата и уведомления

## Уровни доступа

| | Без подписки | Полный доступ |
| --- | --- | --- |
| Вход, навигация, все разделы | ✓ | ✓ |
| Настройка дашбордов и раскладок | ✓ | ✓ |
| Рыночные данные в виджетах | задержанный режим | в реальном времени и история |
| Realtime-карточки (бейдж `Realtime`) | — | ✓ |
| AI Agent и AI-обзоры карточек | — | ✓ |
| Уведомления по метрикам и darkpool | настройка | настройка и доставка |

Для любого уровня нужен аккаунт с **подтверждённым e-mail**. Если подписка закончилась, аккаунт, дашборды и настройки сохраняются, а данные переходят в задержанный режим.

Актуальные периоды и цены — на [странице тарифов](https://app.spy2money.com/tariffs): 1, 3, 6 и 12 месяцев, чем длиннее период, тем ниже цена за месяц.

## Оплата

Выберите период на [странице тарифов](https://app.spy2money.com/tariffs) или в разделе [Оплата](https://app.spy2money.com/app/payment) внутри приложения.

### Банковская карта (через Tribute)

Visa, Mastercard, МИР и другие карты, а также Telegram Stars — через сервис Tribute в Telegram.

1. [Привяжите Telegram](#привязка-telegram) к аккаунту Spy2Money.
2. В Tribute выберите тот же период, что и на платформе, и оплатите.
3. Доступ продлится автоматически для аккаунта с тем же Telegram. Если дата доступа не обновилась, нажмите «Проверить оплату».

### USDT

Поддерживаются сети **Polygon PoS** и **TRON (TRC-20)**. Адрес и QR-код показываются в форме оплаты.

1. Выберите сеть и период, отправьте точную сумму на показанный адрес.
2. Нажмите «Я оплатил», перейдите в Telegram-бот и нажмите «Start».

> Отправляйте USDT только в той сети, которая выбрана в форме. Перевод в другой сети может быть потерян.

## Привязка Telegram

Привязка нужна для оплаты через Tribute и для уведомлений в Telegram.

1. Профиль → «Привязать Telegram».
2. Откроется [@aivix_bot](https://t.me/aivix_bot) с одноразовым кодом (действует 30 минут).
3. Подтвердите привязку в боте — он покажет замаскированный e-mail вашего аккаунта для проверки.

После привязки ожидающие оплаты через Tribute применяются автоматически. Telegram ID в профиле доступен только для чтения.

## Уведомления

Настраиваются в профиле. Каналы доставки:

- **Push в браузере** и на телефоне (PWA или Android-приложение);
- **Telegram** — сообщения от бота после [привязки](#привязка-telegram).

Для каждого канала можно выбрать, какие уведомления получать. Типы уведомлений:

- **Изменения показателей виджетов** — собственные правила по серверным метрикам, например рост Net Premium тикера;
- **Darkpool: резкий всплеск Ask** — ранние алерты по внебиржевым сделкам по всему рынку, включаются отдельно (платная подписка);
- **Сигналы стратегий** — по стратегиям, на которые вы подписаны;
- **Новости**, **Платежи и тариф**, **Системные** и **Маркетинг**.

Настроить уведомления можно без подписки, но рыночные уведомления доставляются только при действующем полном доступе. Один и тот же аккаунт не получает уведомления чаще одного раза в 30 секунд на все устройства.
